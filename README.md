# Hackathon_2025
GAG ME5- Gemnai Ai Game master Edition 5, AI-driven game management platform that combines immersive player interaction with intelligent assistance from Gemini and ChatGPT.

1. Front-End Features
+Player Input System:
-Handles user commands and player actions through an intuitive input module.
+Character Sheet Integration:
-Connects to a structured database for storing and retrieving player stats, inventory, and progression data.
+Includes smooth loading.

2. Backend & Database
+Login & User Management:
-Secure authentication system powered by Docker containers and a PostgreSQL database.
+Data Handling:
-Efficiently stores user profiles, character data, and game session information for persistence and scalability.

3.Ai integretation- using Gemnai Ai to provide real time narration and adaptive story telling by the module integrated by gm and user input.
